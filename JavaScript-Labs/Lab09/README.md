# Lab 09 – JavaScript 2: DOM and Events

Mã nguồn thực hành về DOM, event handling và form validation.

## Chạy bài thực hành

Mở các file HTML trong trình duyệt. Các file dùng CSS, JavaScript và hình ảnh nằm trong các thư mục `css/`, `js/` và `images/` tương ứng. Một số trang dùng Bootstrap hoặc Font Awesome từ CDN.

## Nội dung

- Walkthrough 01–02: quan hệ DOM và duyệt `childNodes`.
- Walkthrough 03: tạo, thêm và xóa phần tử DOM.
- Walkthrough 04: xử lý click, mouseover/mouseout và hiệu ứng ẩn/hiện.
- Walkthrough 05: sự kiện load, mouseover và xác định `event.target` (Exercise 9.5–9.6).
- Walkthrough 07: focus/blur trong form (Exercise 9.7).
- Walkthrough 08: kiểm tra trường trống và hiển thị lỗi (Exercise 9.8).
