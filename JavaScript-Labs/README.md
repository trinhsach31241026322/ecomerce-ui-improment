## Mục tiêu

Thực hành các kiến thức JavaScript qua ba chủ đề: ngôn ngữ JavaScript nền tảng, thao tác DOM và xử lý sự kiện, và sử dụng thư viện jQuery. Repository cung cấp trang chủ để giảng viên xem thông tin sinh viên và mở nhanh từng bài.

## Nội dung các Lab

### Lab 08 – JavaScript 1: Language Foundations

Làm quen với cách nhúng JavaScript, cú pháp và kiểu dữ liệu cơ bản; thực hành mảng, hàm, đối tượng và dữ liệu cho trang du lịch. Mở các walkthrough và bài tập tại [thư mục Lab08](Lab08/).

### Lab 09 – JavaScript 2: DOM and Events

Thực hành duyệt và cập nhật cây DOM, thêm hoặc xóa phần tử, xử lý sự kiện chuột và tải trang, cũng như tương tác và kiểm tra biểu mẫu. Xem [thư mục Lab09](Lab09/).

### Lab 10 – JavaScript 3: jQuery

Thực hành mở rộng JavaScript bằng jQuery, chọn và thao tác phần tử DOM, xử lý sự kiện, hiệu ứng và yêu cầu bất đồng bộ. Các walkthrough hiện có nằm trong [thư mục Lab10](Lab10/).
