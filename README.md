## 1. Giới thiệu bài tập

Bài tập Buổi 2 tiếp tục phát triển website từ Buổi 1, sử dụng HTML5 và CSS3 để cải thiện giao diện, bố cục và cách hiển thị nội dung trên các kích thước màn hình khác nhau.

Website được thực hiện có tên **Góc Mua Sắm**, giới thiệu các sản phẩm khuyến mãi như tai nghe, đồng hồ, giày thể thao và máy ảnh mini.

## 2. Website tham khảo và khu vực cải tiến

- **Website tham khảo:** [Shopee](https://shopee.vn/)
- **Khu vực đã cải tiến:** Menu điều hướng và khu vực hiển thị sản phẩm.
- **Nội dung cải tiến:** Định dạng menu theo hàng ngang, điều chỉnh bố cục thẻ sản phẩm và cải thiện cách hiển thị trên các kích thước màn hình.

## 3. Kỹ thuật HTML5/CSS3 đã thực hành

- **HTML5:** Sử dụng các thẻ `header`, `main`, `section`, `article` và `footer` để tổ chức nội dung.
- **CSS selector:** Sử dụng bộ chọn phần tử, class và pseudo-class.
- **Box Model:** Thực hành `margin`, `padding`, `border` và `box-sizing`.
- **Flexbox:** Sắp xếp các thành phần menu và thông tin giá sản phẩm.
- **CSS Grid:** Sắp xếp các thẻ sản phẩm theo dạng lưới.
- **Responsive Design:** Sử dụng Media Queries để điều chỉnh bố cục theo kích thước màn hình.
- **Hover/Focus:** Định dạng trạng thái tương tác của các liên kết và nút bấm.

## 4. Hướng dẫn chạy website

1. Tải hoặc clone repository về máy tính.
2. Mở thư mục dự án.
3. Mở file `my store/index.html` bằng trình duyệt web.
4. Kiểm tra giao diện, hình ảnh, liên kết và bố cục của website.

File CSS được lưu riêng tại `my store/css/style.css` và liên kết với HTML thông qua thẻ `<link>`.

## 5. Những thay đổi đã thực hiện

- Định dạng menu điều hướng thành hàng ngang và loại bỏ dấu chấm đầu dòng.
- Điều chỉnh giao diện thẻ sản phẩm, hình ảnh và thông tin giá.
- Sử dụng CSS Grid để bố trí sản phẩm.
- Bổ sung Media Queries để thay đổi số cột theo kích thước màn hình.

- **Mục đích sử dụng:** Hỗ trợ giải thích HTML5/CSS3, đề xuất cách cải thiện giao diện và gợi ý kiểm tra lỗi.
- **Prompt tiêu biểu:** Tôi đang thực hiện bài tập cải tiến giao diện thẻ sản phẩm cho website thương mại điện tử bằng HTML5 và CSS3. Hãy hỗ trợ tôi phân tích giao diện website Shopee Việt Nam, đề xuất cách cải thiện bố cục thẻ sản phẩm và hướng dẫn chỉnh sửa mã HTML, CSS.
